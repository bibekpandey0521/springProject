# Spring Boot Project

This is a Spring Boot project where I am building various modules to manage departments and their associated functionalities. 

## Features
- **Download Department PDF**: Allows users to download department-related PDFs.
- **Department List**: Displays a list of departments dynamically.

## Getting Started
To run the project locally:

1. Clone the repository:
    ```bash
    git clone https://github.com/bibekpandey0521/springProject.git
    ```

2. Navigate to the project directory and run:
    ```bash
    mvn spring-boot:run
    ```

## Technologies Used
- Spring Boot
- Maven
- Java
- Thymeleaf
- Tailwind CSS
