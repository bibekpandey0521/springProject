# 🧩 Spring Boot CRUD Project

A modular and beginner-friendly **Spring Boot** web application using **Thymeleaf** and **Tailwind CSS**, focused on implementing basic CRUD functionality. The project includes a responsive UI and a reusable structure for building out multiple modules like departments, doctors, patients, etc.

## 📌 Current Features

- ✅ Navbar (using a reusable header layout)
- ✅ Department Module (Create, Read, Update, Delete)
- ✅ Tailwind CSS integration for styling
- 🛠️ Modular file structure for reusability

> 🛠️ _Other modules like Doctor, Patient, etc. are under development._
